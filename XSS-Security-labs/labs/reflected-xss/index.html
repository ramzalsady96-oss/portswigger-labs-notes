SECURITY COMPARISON

Before vs After

Before Remediation

  • User input is treated as trusted.
  • Input reaches an HTML rendering sink.
  • HTML is interpreted by the browser.
  • The application is vulnerable to XSS.

After Remediation

  • User input is treated as untrusted.
  • Data is inserted using safe DOM APIs.
  • User input is rendered as text.
  • The original XSS behavior is prevented.
